# Game of Life

![HTML](https://img.shields.io/badge/HTML-5-e34f26?style=flat-square&logo=html5&logoColor=white)
![JavaScript](https://img.shields.io/badge/JavaScript-vanilla-f7df1e?style=flat-square&logo=javascript&logoColor=black)

An interactive Conway's Game of Life experiment. Click cells to toggle them between alive and dead, then start the simulation to evolve the grid every 500 milliseconds.

## Setup and run

No dependencies or build step are required. Open [`gameoflife.html`](./gameoflife.html) directly in a browser, or serve this directory:

```bash
cd GameOfLife
python3 -m http.server 8000
```

Open `http://localhost:8000/gameoflife.html`.
