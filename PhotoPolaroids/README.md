# Photo Polaroids

![Browser-only](https://img.shields.io/badge/app-browser--only-2ea44f?style=flat-square)
![JavaScript](https://img.shields.io/badge/JavaScript-vanilla-f7df1e?style=flat-square&logo=javascript&logoColor=black)

Photo Polaroids is a local photo pairing tool. Select images from your device, pair them into print previews, reframe the images, and export print-ready 4 × 6 JPEGs. Images stay in the browser.

## Setup and run

No installation or build step is required. Open [`index.html`](./index.html) directly, or serve the project locally:

```bash
cd PhotoPolaroids
python3 -m http.server 8000
```

Open `http://localhost:8000`.
